Bem-vindo ao FoxFlow!

O FoxFlow é um sistema básico de gerenciamento de vendas desenvolvido para colocar em prática conhecimentos de desenvolvimento web e back-end.

A ideia não é ser um sistema completo ou complexo, mas um projeto simples que me ajudou a treinar a integração entre HTML, Java, Spring Boot e PostgreSQL, entendendo melhor como essas tecnologias trabalham juntas.

Desenvolvido por Gabrielle Rocha.
