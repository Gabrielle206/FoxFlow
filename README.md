## ✦ Sobre o projeto

O **FoxFlow** é um sistema básico de gerenciamento de vendas desenvolvido para colocar em prática conhecimentos de **desenvolvimento web e back-end**.

A ideia não é ser um sistema completo ou complexo, mas um **projeto simples** que me ajudou a treinar a integração entre **HTML, Java, Spring Boot e PostgreSQL**, entendendo melhor como essas tecnologias trabalham juntas.

<br/>

## ✦ O que eu pratiquei

- Integração entre **front-end** e **back-end**
- Criação de uma aplicação web com **Spring Boot**
- Conexão da aplicação com um banco de dados **PostgreSQL**
- Criação de páginas HTML dinâmicas com **Thymeleaf**

<br/>

## ✦ Funcionalidades

- Cadastro de **produtos**
- Listagem de **produtos** cadastrados
- Área administrativa (`/adm`)

## ✦ Tecnologias

| Tecnologia | Uso no projeto |
|---|---|
| **Java** | Linguagem de desenvolvimento do back-end |
| **Spring Boot** | Framework da aplicação web |
| **Thymeleaf** | Criação das páginas HTML integradas ao Java |
| **Bootstrap 4.1.3** | Estilo e layout das páginas |
| **PostgreSQL** | Banco de dados relacional |
| **HTML** | Estrutura das páginas |

<br/>

## ✦ Como executar

**Requisitos:** JDK, PostgreSQL e uma IDE para Java (ou Maven).

1. Clone o repositório:
   ```bash
   git clone https://github.com/Gabrielle206/FoxFlow.git
   ```
2. Crie um banco de dados no PostgreSQL.
3. Configure a conexão (endereço, usuário e senha) no arquivo `application.properties`.
4. Execute a aplicação pela IDE ou, se o projeto usar Maven, com:
   ```bash
   ./mvnw spring-boot:run
   ```
5. Acesse no navegador: `http://localhost:8080/adm`
