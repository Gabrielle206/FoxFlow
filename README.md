# 🦊 FoxFlow

O **FoxFlow** é um sistema básico de gerenciamento de vendas desenvolvido para colocar em prática conhecimentos de desenvolvimento web e back-end.

A ideia não é ser um sistema completo ou complexo, mas um projeto simples que me ajudou a treinar a integração entre **HTML**, **Thymeleaf**, **Java**, **Spring Boot** e **PostgreSQL**, entendendo melhor como essas tecnologias trabalham juntas.

---

## 🛠️ Tecnologias utilizadas

- **Java**
- **Spring Boot**
- **Spring Data JPA**
- **Thymeleaf**
- **PostgreSQL**
- **HTML**
- **Maven**

---

## ✨ Funcionalidades

- Cadastro de produtos
- Registro de vendas
- Listagem, edição e exclusão de registros

---

## 📋 Pré-requisitos

Antes de começar, você vai precisar ter instalado:

- [Java JDK 17+](https://www.oracle.com/java/technologies/downloads/)
- [Maven](https://maven.apache.org/)
- [PostgreSQL](https://www.postgresql.org/download/)
- [Git](https://git-scm.com/)

---


## 🎯 Objetivo do projeto

Este projeto foi criado com fins de estudo, para praticar:

- Criação de rotas e controllers com Spring Boot
- Renderização de páginas dinâmicas com Thymeleaf
- Integração entre front-end (HTML) e back-end (Java)
- Persistência de dados com PostgreSQL
- Organização de um projeto em camadas
